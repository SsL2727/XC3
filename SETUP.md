# Xenoblade Chronicles 2 & 3 — Setup Guides

Each game has its own complete, step-by-step setup guide (they use different emulators and have different
options):

- **[SETUP_XC2.md](SETUP_XC2.md)** — Xenoblade Chronicles 2 (runs on Ryujinx)
- **[SETUP_XC3.md](SETUP_XC3.md)** — Xenoblade Chronicles 3 (runs on Eden)

Both cover: writing a player YAML, generating a seed, hosting, patching, launching the emulator, connecting the
client, playing, and troubleshooting — for everyone on one machine with a local server.

If the host and a player are on **different computers**, using the official [archipelago.gg](https://archipelago.gg)
website to host instead of a local server, see **[SETUP_XC3_REMOTE.md](SETUP_XC3_REMOTE.md)** instead (XC2 follows
the same shape, swap the XC2-specific paths from SETUP_XC2.md in).

For the technical/developer reference (how the worlds are built, data formats, etc.) see [README.md](README.md)
instead.
